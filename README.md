# 나에게 묻는 질문 — 웹앱 배포·운영 안내

로그인 없이 쓰는 자기대화 웹앱이에요. 서버 없이 파일만 올리면 작동해요.

## 폴더 구성
- `index.html` : 앱 전체 (화면, 대화, 세월 효과, AI 연결, 내보내기, 개인정보 안내)
- `manifest.webmanifest`, `icon.svg`, `icon-192.png`, `icon-512.png` : 휴대폰 "홈 화면에 추가"용
- `version.json` : 지금 올라간 버전 번호. 수정할 때마다 같이 바꿔요.

## 1. 올리기 (무료, 약 10분)
추천: **GitHub + Vercel** (또는 Netlify, Cloudflare Pages도 같은 방식)
1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 모두 올려요.
2. vercel.com에 GitHub 계정으로 가입 → New Project → 저장소 선택 → Deploy.
3. `프로젝트이름.vercel.app` 주소가 생겨요. 이 링크로 바로 공유하면 돼요.
4. 원하면 도메인을 사서 연결할 수 있어요 (연 1~2만 원대).

## 2. 수정하면 자동 반영
- GitHub의 파일을 고치고 저장(commit)하면 1분 안에 사이트가 자동으로 바뀌어요.
- 사용자는 새로고침만 하면 최신 버전을 봐요. 앱스토어 앱처럼 업데이트를 따로 받을 필요가 없어요.
- **쓰고 있는 사람에게도 반영돼요.** 수정해서 올릴 때 `index.html`의 `CONFIG.version`과 `version.json`의 숫자를 같이 올려주세요(예: `2026.11.22-2`). 앱이 5분마다, 그리고 화면으로 돌아올 때마다 확인해서 "새 버전이 나왔어요" 버튼을 띄워요. 대화 중이면 대화가 사라지지 않게 먼저 한 번 경고해요.
- 수정은 Claude에게 "index.html에서 ○○ 바꿔줘" 하고, 받은 파일로 교체하면 돼요.

## 3. 익명 통계 켜기 (선택)
쿠키를 쓰지 않는 Umami를 추천해요.
1. umami.is에서 무료로 가입하고 웹사이트를 추가해요.
2. 받은 스크립트 주소와 웹사이트 ID를 `index.html` 맨 아래의 `CONFIG`에 넣어요.
   ```js
   analyticsSrc:'https://cloud.umami.is/script.js',
   analyticsId:'여기에-웹사이트-ID',
   contact:'운영자@이메일'
   ```
3. Umami 대시보드에서 방문자 수, 머문 시간, 재방문, 아래 이벤트를 볼 수 있어요.

| 이벤트 | 뜻 |
|---|---|
| `first_visit` | 처음 온 사용자 |
| `question_open` | 질문을 눌러봄 (어떤 질문인지) |
| `conv_start` | 대화 시작 (화면·대화 방식·몰입 모드) |
| `msg` | 메시지 1개 보냄 (내용은 보내지 않음) |
| `conv_end` | 대화 종료 (보낸 메시지 수) |
| `export` | 대화 내보내기 |
| `guide_done` | 안내 흐름을 끝까지 마침 |
| `photo_added`, `ai_connected`, `recommend` | 사진 추가, AI 연결, 질문 추천 |

대화 내용, 이름, 나이, 사진은 어떤 이벤트에도 들어가지 않아요. 첫 화면의 '시작하기'에 통계 안내가 포함돼 있고, 설정 안쪽에서 끌 수도 있어요.

## 4. 질문 추가하기
공개 파일(index.html)에는 공개한 질문만 들어 있어요. 웹사이트 코드는 누구나 열어볼 수 있어서, 공개 전 질문은 이 폴더 밖 비공개 파일에만 보관해요.
새 질문을 공개할 때는 `index.html`의 `const Q=[…]`에 질문을 추가하고, `FLOWS`에 그 질문의 안내 흐름을 추가하면 돼요.

## 5. 출시 전 체크리스트
- [ ] `CONFIG.contact`에 문의 이메일 넣기 (개인정보 처리방침에 표시됨)
- [ ] 개인정보 처리방침 문구를 전문가에게 한 번 검토받기 (앱 안 '개인정보 처리방침')
- [ ] 휴대폰에서 사진 넣고 세월 효과·나이 든 사진 넣기 확인
- [ ] AI 연결은 실제 API 키로 한 번 테스트 (모델 이름은 설정에서 바꿀 수 있어요)

## 6. AI 연결 구조
- 사용자가 설정에서 **본인 API 키**를 넣어야 작동해요. 요금은 사용자 본인 API 계정에 청구돼요.
- 키와 대화는 사용자 기기에서 Anthropic/OpenAI로 **직접** 가요. 운영자 서버를 거치지 않아요.
- 나중에 "앱이 AI를 제공하는 유료 플랜"을 만들려면 서버(API 키 보관 + 결제)가 따로 필요해요.
