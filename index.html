지금, 어떤 순간인가요?

상황을 고르면 그 순간에 맞는 질문과 대화 상대가 기다리고 있어요.

당신의 대화는 오직 이 기기에만 있어요.

대화 내용, 사진, 이름, 나이는 서버에 저장하지 않고 읽지도 않아요. 앱을 더 좋게 만들기 위해 '몇 번 대화했는지' 같은 숫자만 이름 없이 모아요.

사진은 이 기기 안에서만 쓰이고 어디로도 보내지 않아요.
이 앱은 상담이나 치료를 대신하지 않아요. 마음이 많이 힘들 때는 자살예방상담전화 109로 언제든 연락하세요.

고르면 시간 여행 장면과 대화에 반영돼요. 모르겠으면 그냥 두세요.

노화 필터 앱(예: FaceApp)으로 만든 사진을 넣으면, 시간 여행 끝에 그 얼굴로 나타나요.

대화 방식

AI 연결 (선택)

연결하지 않아도 '직접 쓰기'와 '안내 받기'로 모든 대화를 할 수 있어요.

지금은 Claude 앱 안에서 열려 있어요.

내 Claude 계정으로 AI 기능이 바로 작동해요. 별도 연결이 필요 없어요.

비용 안내
  • 이 앱은 무료예요. 우리는 어떤 요금도 받지 않아요.
  • AI 기능은 본인의 API 키로 작동하고, 사용한 만큼 API 요금이 본인 계정에 청구돼요.
  • ChatGPT Plus나 Claude Pro 같은 구독과는 별개예요. 구독 중이어도 API 요금은 따로 나가요.
  • 정확한 요금은 각 회사의 API 요금표를 확인하세요.
어떤 AI를 연결할까요?

모델 이름은 자주 바뀌어요. 오류가 나면 각 회사 문서에서 최신 이름을 확인해 바꿔주세요.

API 키는 이 기기의 브라우저에만 보관되고, 우리 서버로는 절대 전송되지 않아요. 체크하지 않으면 창을 닫을 때 지워져요. 공용 기기에서는 체크하지 마세요.

AI 모드에서는 대화 내용이 연결한 회사(Anthropic 또는 OpenAI)로 이 기기에서 직접 전송돼요. 우리를 거치지 않아요.
